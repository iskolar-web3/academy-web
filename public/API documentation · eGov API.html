Push SMS

POST{{base_url}}/messaging/v1/sms/push

Sends an SMS message to a recipient number.

Headers

Header Value Required Description
X-EMESSAGE-Auth <API-TOKEN> Yes eMessage API auth token.
Content-Type application/json Yes Request body is JSON.

Body Parameters

Field Type Required Description
number string Yes Recipient mobile number in E.164 format, e.g. +639090000000.
message string Yes The SMS message body.

Headers

KeyValueDescription
X-EMESSAGE-Auth{{api_token}}

eMessage API auth token.

Body · raw

Request body
{
  "number": "+639090000000",
  "message": "Test message"
}

Example request

cURL
curl --request POST \
  --url '{{base_url}}/messaging/v1/sms/push' \
  --header 'X-EMESSAGE-Auth: {{api_token}}' \
  --header 'Content-Type: application/json' \
  --data '{
    "number": "+639090000000",
    "message": "Test message"
}'

{
  "data": {
    "message": "SMS was successfully created."
  }
}

Anchor records and run smart contracts on a zero-fee government blockchain (Hyperledger Besu) over JSON-RPC, for tamper-evident, verifiable state.

Postman Collection v2.1 for the DICT eGov hackathon Hyperledger Besu QBFT node.

Zero fees — all transactions use gasPrice: 0 (no ETH needed for gas).

For participants

This collection covers the APIs you need to build on the hackathon chain:
ETH, NET, WEB3, TXPOOL, and read-only QBFT.

Operator-only APIs (ADMIN, DEBUG, TRACE) are not included.

Setup

  1. Import this collection + egov-hackathon-besu.postman_environment.json
  2. Activate environment DICT eGov Hackathon — Besu (zero fees)
  3. Defaults: RPC https://hackathon-blockchain.e.gov.ph, explorer https://hackathon-explorer.e.gov.ph

Folders

  • Besu JSON-RPC — participant-facing Besu methods
  • Contracts — HackathonGuestbook — demo contract eth_call samples

Deploy your own contracts

You can deploy your own smart contracts to this hackathon chain and use them in your project.

  • RPC: https://hackathon-blockchain.e.gov.ph
  • Chain ID: 13371
  • Gas price: 0 (zero fees)
  • Explorer: https://hackathon-explorer.e.gov.ph

Use Remix, Hardhat, Foundry, MetaMask, or any Ethereum tooling pointed at that RPC.

POST{{rpcUrl}}

rpc_modules

Lists enabled JSON-RPC API namespaces on this Besu node.

Method: rpc_modules

Params:

[]

Returns: Object mapping namespace → version (e.g. eth, net, web3).

Zero fees: this chain uses gasPrice: 0 (eth_gasPrice → 0x0).
